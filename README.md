# MTA Daily Ridership Analysis & Forecasting
**DEPI Graduation Project - Round 5 - Group 5**

## 📖 Project Overview
This project analyzes historical MTA Daily Ridership data to uncover trends, answer key business questions, and forecast future ridership. The final output includes a cleaned dataset, analysis notebooks, machine learning models, and a Tableau dashboard.

## 🎯 Project Objectives
- **Week 1:** Data cleaning, preprocessing, and building a robust data model.
- **Week 2:** Formulating and answering analytical questions using SQL and Python.
- **Week 3:** Developing forecasting models (scikit-learn) to predict next-month ridership.
- **Week 4:** Building a Tableau dashboard and preparing the final presentation.

## 🛠️ Tech Stack
- **Languages:** Python, SQL
- **Libraries:** Pandas, Matplotlib, Scikit-learn
- **Visualization:** Tableau
- **Version Control:** Git / GitHub

## 📂 Repository Structure
- `data/` - Raw and cleaned datasets
- `notebooks/` - Jupyter notebooks for preprocessing, analysis, and forecasting
- `sql/` - SQL scripts for data extraction and querying
- `dashboard/` - Tableau workbook files and screenshots
- `reports/` - Final project report and presentation slides
